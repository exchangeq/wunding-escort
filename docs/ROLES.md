# 四端分工与权限

系统按四个角色分开入口，账号都由董事长或管事在后台创建，不需要手工改 JSON。

| 角色 | 入口 | 主要做什么 |
| --- | --- | --- |
| 董事长 owner | `/admin/` | 看全局数据、管所有账号和权限、改站点与支付、查操作日志 |
| 管事 manager | `/manager/` | 排单派单、改商品价格和上下架、建客服/打手账号、改站点文案 |
| 客服 support | `/support/` | 接待订单、核对付款截图、确认到账、跟进进度、写内部备注 |
| 打手 booster | `/staff/` | 接单、上号、提交进度和配图、标记完成 |

默认只有董事长账号 `wunding / wunding2026`。第一次登录后到「团队账号」里建客服、打手、管事，再把密码发给对应的人。

## 订单怎么走

1. 客户在前台下单，订单进入「待接单 / 待付款」。
2. 客户传付款截图，或走易支付回调，订单变成「待确认付款」。
3. 客服在 `/support/` 核对截图，点「确认到账」，订单变成「已到账」。
4. 已到账且没派人的订单会进入打手端「可接单」池；管事也可以在 `/manager/` 直接指定打手。
5. 打手接单后订单变「护航中」，可以反复提交进度（最多留 30 条，可配一张图）。
6. 打手点「完成」后订单变「已完成」；客户在 `/track.html` 输入订单号能看到打手名字和进度。

打手在接单池里只看到「已付款、待接单、未派单」的订单，手机号做了脱敏，也看不到付款截图。打手只能操作派给自己的订单。

## 账号管理

- 新建账号要填姓名、登录账号、初始密码（至少 6 位）、角色；打手额外填分成比例（只用于工作量估算展示，不涉及自动结算）。
- 管事只能建客服和打手。想提一个管事，得找董事长。
- 停用账号后该账号立即登录不了；已经登录的令牌到期前仍有效，介意的话让对方退出或改密码。
- 重置密码后旧密码立刻失效，新密码由管事或董事长告诉本人。
- 删除账号不会删他名下的历史订单，订单里的打手名字会保留。

## 打手端

打手端按手机屏幕做的，Termux 或服务器跑起来后，手机浏览器直接开 `http://服务器IP:8080/staff/`，可以加到桌面当 App 用。

- 「可接单」是公共池，先到先得；点「接这单」后进入「我的任务」。
- 「我的任务」里点「看详情 / 报进度」，可以写一句进度、配一张图（3MB 以内），客户在订单查询页能同步看到。
- 没上号之前订单是「待接单」，点「开始打」变成「护航中」；打完点「标记完成」。
- 分成金额只是按订单金额 × 分成比例算的参考值，系统不自动打款，结算仍由工作室线下处理。

## 操作日志

登录、建号、改密码、停用账号、派单、确认到账、改订单状态、改商品和站点设置都会写一条日志，董事长和管事在「操作日志」里按时间倒序看。日志只记录动作，不记录密码和商户密钥。
